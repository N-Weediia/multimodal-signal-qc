# 多模态信号处理与质量门控规范

本规范详细定义多模态脑机与运动功能评估系统（EEF_analyze）中 EEG、sEMG 和 fNIRS 三大模态的硬件参数、信号清洗流程、通道/样本级质量门控策略与审计掩码体系。

---

## 1. 脑电 (EEG) 处理与门控规范

### 1.1 硬件参数与电极帽布局
- **采集硬件**：博睿康 Neuracle NeuSen W 64，24-bit 精度，原始采样率 1000 Hz，存储为 BDF 格式。
- **64 导标准配置（EEGCap64-V3.0）**：
  - **59 个头皮记录导联**：覆盖额极、额叶、额中央、中央、顶叶、颞叶及枕叶（基于国际 10-10 系统）。
  - **2 个参考与接地**：系统预设参考电极（REF）与地电极（GND）。
  - **5 个外加生理辅助导联**：`ECG`（心电）、`HEOR`/`HEOL`（水平眼电双侧）、`VEOU`/`VEOL`（垂直眼电上下）。辅助导联**严格不参与**头皮平均/中位数重参考，亦不套用头皮阻抗或幅值评分。
- **32 导缩减配置（特殊受试者）**：
  - 仅限于 `2026081701` 与 `2026081801` 的 `base_line` 访视。
  - 实际注胶的 31 个头皮导联为：`Fpz, Fp1, Fp2, Fz, F3, F4, F7, F8, FCz, FC1, FC2, FC5, FC6, Cz, C3, C4, T7, T8, CP1, CP2, CP5, CP6, Pz, P3, P4, P7, P8, POz, Oz, O1, O2`。未启用的 28 个导联在质控中归为 `UNENABLED`，不予判罚。

### 1.2 信号清洗管线与算法
1. **稳健逐采样中位数重参考 (Robust Median Re-referencing)**：
   - 传统平均参考易被少数坏导或大幅伪迹污染，并将工频扩散至全脑。本管线仅在启用的头皮导联集合上计算各时刻样本的中位数，构造虚拟参考并扣除。
2. **频域滤波**：
   - 50 Hz 二阶 IIR 陷波器（Notch Filter，Q=30）；
   - 0.5--45 Hz 零相位 Butterworth 带通滤波。
3. **降采样**：抗混叠滤波后重采样至 250 Hz。

### 1.3 质量门控与掩码契约 (`eeg_cleaned.npz`)
- **坏导检测规则**：
  - 平线导联：峰峰值（Peak-to-Peak）$< 2.0\ \mu\text{V}$；
  - 饱和/极值导联：采样值超出动态测量范围或重复极值；
  - 高阻抗/接触不良：异常高频噪声或方差离群（超过全脑中位数 4 倍）。
- **空间插值与掩码**：
  - 孤立坏导联允许采用球面样条或局部近邻空间插值进行恢复，以维持通道拓扑完整。
  - **铁律约束**：所有坏导与插值导必须记录在 `bad_channel_mask` 和 `interpolated_channel_mask` 中。**下游统计分析严禁将插值导联作为独立观测变量！**
- **时间分段掩码 (`valid_2s_epoch_mask`)**：
  - 信号切分为 2.0 秒无重叠窗口；
  - 若任一有效头皮通道在当前 2 秒窗口内峰峰值 $> 200.0\ \mu\text{V}$，或整体位移（超 20% 导联同时异常），则标记 `valid_2s_epoch_mask = False`。
  - 有效分析时段仅在掩码为 `True` 的区间内提取。

## 2. 表面肌电 (sEMG) 与 IMU 运动学规范

### 2.1 硬件参数与肌肉映射
- **硬件设备**：Delsys Trigno / Avanti 无线表面肌电系统，原始采样率约 1000--2000 Hz，导出为 CSV 文件。
- **物理传感器与逻辑肌肉对应规范**：
  - 实验方案设定 7 块评估肌肉（逻辑肌肉索引 1--7）。
  - **标准受试者映射表**：
    | 逻辑肌肉索引 | 目标肌肉名称 | 标准物理传感器 ID |
    | :---: | :--- | :---: |
    | **1** | 上斜方肌 (Trapezius Upper) | **2** |
    | **2** | 三角肌前束 (Anterior Deltoid) | **3** |
    | **3** | 三角肌中束 (Medial Deltoid) | **4** |
    | **4** | 肱二头肌 (Biceps Brachii) | **5** |
    | **5** | 肱三头肌 (Triceps Brachii) | **9** |
    | **6** | 肱桡肌 (Brachioradialis) | **10** |
    | **7** | 尺侧腕屈肌 (Flexor Carpi Ulnaris) | **11** |
  - **特殊受试者偏移配置 (`shifted_v1`)**：
    - 已确认 `2026080901` 的 `base_line` 访视整体传感器贴附前移一位。
    - 采用 `shifted_v1` 配置：物理传感器 `1, 2, 3, 4, 5, 9, 10` 分别映射为逻辑肌肉 `1--7`。
  - **缺失传感器规则**：物理传感器 6、7、8 在本方案中未采购/未贴附，**不得**视作数据丢失；未知记录中的传感器 1 不得擅自盲目重排。

### 2.2 信号处理与质量门控 (`emg_cleaned.npz`)
- **无事件连续会话**：Delsys CSV 未内嵌任务阶段，预处理作为连续时间序列输出，任务分段依赖外部同步日志。
- **滤波**：
  - 20--450 Hz 零相位带通滤波（抑制动伪迹与高频底噪）；
  - 50 Hz 工频及其高次谐波（100, 150, 200, 250, 300, 350, 400 Hz）陷波滤波；
  - 重采样至统一 1000 Hz。
- **通道分级与入组门控**：
  - `GOOD` / `CAUTION`：幅值、信噪比与工频谐波占比合格，进入下游协同（Synergy/NMF）、共激活（Coactivation）分析。
  - `POOR` / `UNKNOWN`：严重掉线或噪声污染，仅作审计留痕，不得参与主特征统计。
- **幅值单位提示**：CSV 表头未声明工程单位，所有 RMS、MAV 与包络计算严禁擅自假定为 $\text{mV}$ 或 $\mu\text{V}$，统一保留源文件原生单位。

### 2.3 Avanti IMU (Acc / Gyro / Mag) 姿态与运动代理
- **数据源**：同一 CSV 中伴随导出的三轴加速度（Acc）、陀螺仪（Gyro）与磁力计（Mag）时序。
- **1 秒运动学代理 (`imu_kinematic_proxy_1s.csv`)**：
  - 基于重力加速度向量分解的倾角代理：`roll_proxy_deg`、`pitch_proxy_deg`。
  - 动态运动强度代理：动态加速度 RMS 与角速度模长 RMS。
- **姿态置信度门控**：
  - `PASS_SOURCE_UNIT_HEURISTIC`：加速度向量模长落在 $[0.75, 1.25]$ 区间且覆盖率 $\ge 50\%$。
  - **解释红线**：
    - `orientation_status = TILT_PROXY_ONLY`（仅限倾角代理）；
    - `gyro_status = DYNAMIC_RATE_ONLY`（仅为角速度动态强度，严禁无偏置积分角度）；
    - `yaw_status = UNAVAILABLE_MAG_UNCALIBRATED`（磁力计未校准，航向角不可用）。
    - 严禁声称结果为“人体刚体绝对姿态”或“关节运动学轨迹”。

## 3. 近红外脑功能成像 (fNIRS) 规范

### 3.1 硬件参数与通道配对
- **采集硬件**：丹阳慧创 NirSmart 便携式 fNIRS，双波长 730 nm 与 850 nm，存储为 Homer `.nirs` 格式。
- **物理通道配对**：发射源（Source）与探测器（Detector）构成的物理测量通道。

### 3.2 信号清洗与修正流程
1. **原始光强向自然对数光密度 (OD) 转换**：
   $$\Delta \text{OD}(\lambda, t) = -\ln\left(\frac{I(\lambda, t)}{I_0(\lambda)}\right)$$
   其中 $I_0$ 取基线均值。严禁未作校验即自动调用 MBLL 计算 HbO/HbR。
2. **通道质量初筛阈值**：
   - **头皮耦合指数 (SCI)**：提取 0.5--2.5 Hz 心搏波段，计算 730 nm 与 850 nm 互相关系数。$\text{SCI} < 0.50$ 直接剔除，$\text{SCI} < 0.80$ 标记预警。
   - **变异系数 (CV)**：两波长光强标准差与均值比值。$\text{CV} > 15\%$ 直接剔除，$\text{CV} > 7.5\%$ 标记预警。
3. **突发尖峰与基线阶跃修复**：
   - 应用自适应 Hampel 局部中位数滤波与 TDDR-like 阶跃抑制；
   - 0.01--0.2 Hz 零相位带通滤波（滤除心搏高频与超低频漂移）。

### 3.3 红外眼动已知干扰规范 (`READY_WITH_MASKS_KNOWN_IR_INTERFERENCE`)
- **干扰机理**：在眼动认知任务中，眼动仪发射的红外照明光源（通常在 850 nm 附近）直接穿透头部射入 fNIRS 探头，造成原始光强虚假突增与通道饱和。
- **状态契约**：
  - 眼动记录不应直接粗暴全盘剔除，亦不可假装未受干扰；
  - 标记为 `READY_WITH_MASKS_KNOWN_IR_INTERFERENCE`，会话质量降级至 `CAUTION`；
  - 输出中包含 `wavelength_valid_sample_mask`、`motion_artifact_mask` 与 `analysis_sample_mask`；
  - 默认分析必须严格结合 `analysis_sample_mask` 仅评估未饱和采样点。

## 4. 质量门控状态码全览

| 状态码 | 含义说明 | 下游分析权限 |
| :--- | :--- | :--- |
| `READY` / `READY_WITH_MASKS` | 预处理成功，各项指标合格，附带精细质量掩码 | 允许进行主特征提取与组间分析，须严格带掩码 |
| `READY_CHANNEL_FILTERED` | 部分通道因阻抗或接触剔除，剩余通道可用 | 允许在剩余通道子集内分析，不得插值恢复被剔除导 |
| `READY_CONTINUOUS` | 连续信号可用，但缺少事件标记或无法精细分段 | 仅允许作为连续静息态或全段特征分析 |
| `READY_WITH_MASKS_KNOWN_IR_INTERFERENCE` | 存在红外眼动交叉干扰，但有效样本已成功隔离掩码 | 仅允许在敏感性分析分支中使用，不可代表绝对血氧 |
| `FAILED` / `UNASSESSABLE` | 记录过短（<2s）、文件损坏、无法解析或严重伪迹 | 严禁进入下游特征统计与模型训练 |
